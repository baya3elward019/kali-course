02 / THE FOUNDATION

يعني إيه Linux؟

🧠

النواة Kernel

هي الجزء الأساسي اللي بيدير المعالج والذاكرة والأجهزة والعمليات، وبتوفر للتطبيقات طريقة تتعامل بيها مع الهاردوير.

اللي بنسميه غالبًا «لينكس» بيكون نواة Linux مع أدوات النظام، ومكتبات، ومدير حزم، وواجهة رسومية أو سطر أوامر.

قبل ما نكتب أول أمر

Kali Linux — Terminal

شكل الـ prompt يختلف حسب اسم المستخدم وإعدادات الطرفية؛ النتائج هنا أمثلة توضيحية.

شكل الأمر

COMMAND STRUCTURE
command [options] [arguments]

الأمر: البرنامج المطلوب تشغيله.

Flag / Option: يعدّل طريقة عمل الأمر، مثل -l.

Argument: الشيء اللي هنطبق عليه الأمر، مثل اسم ملف.

خلي بالك: لينكس غالبًا حساس لحالة الأحرف؛ File.txt مختلف عن file.txt.
1. اقرأافهم الأمر والـ flags
2. جرّبابدأ بأوامر قراءة آمنة
3. تحقّقراجع الناتج قبل أي تعديل
05 / NAVIGATION

التنقل ومعرفة مكانك

pwdPrint Working Directory

يعرض المسار الحالي.

pwd
pwd -P
-P يعرض المسار الفعلي بدون روابط رمزية.
lsList files

يعرض الملفات والمجلدات.

ls
ls -l
ls -la
ls -lh
-l تفاصيل · -a المخفي · -h أحجام مقروءة مع العرض الطويل.
cdChange directory

ينقلك بين المجلدات.

cd ~
cd /tmp
cd ..
cd -
~ مجلد المنزل · .. المجلد الأب · - المكان السابق. cd مش محتاج flags شائعة.
tree / fileInspect paths

عرض بنية المجلد أو معرفة نوع الملف.

file /etc/passwd
tree -L 2 /tmp
tree -L 2 يحدد عمق العرض. لو tree مش مثبت، استخدم ls -R /tmp أو تخطَّ المثال.
تجربة مباشرة آمنة: نفّذ pwd ثم ls -la ثم cd /tmp ثم pwd، وبعدها cd -.
06 / FILES & DIRECTORIES

إنشاء الملفات ونسخها ونقلها

mkdirCreate directory

إنشاء مجلد.

mkdir linux-demo
mkdir -p linux-demo/docs/notes
-p ينشئ المسارات الأب المطلوبة، ولا يعتبر خطأ لو المجلد موجود.
touchCreate / timestamp

ينشئ ملفًا فارغًا لو مش موجود، أو يحدّث وقت الملف.

touch linux-demo/hello.txt
touch linux-demo/notes.txt
لا يكتب نصًا داخل الملف.
cpCopy

نسخ ملف أو مجلد.

cp linux-demo/hello.txt /tmp/
cp -i linux-demo/hello.txt /tmp/hello-copy.txt
cp -r linux-demo /tmp/linux-demo-copy
-i يسأل قبل الاستبدال · -r نسخ مجلد بمحتوياته.
mvMove / Rename

نقل ملف أو تغيير اسمه.

mv linux-demo/notes.txt linux-demo/renamed.txt
mv -i linux-demo/renamed.txt /tmp/
-i يطلب التأكيد قبل استبدال ملف موجود.
نصيحة للديمو: ابدأ بـ mkdir -p ~/linux-demo وبعدها نفّذ أمثلة الإنشاء داخل ~/linux-demo لتفضل ملفات العرض منظمة في مجلد واحد.
ترتيب الأمثلة: أوامر هذه الشريحة أمثلة مستقلة تُنفّذ من مجلد المنزل بعد cd ~. قد تكتب بعض أمثلة cp وmv فوق وجهة موجودة؛ استخدم الديمو المحصور في الشريحة 13 أثناء المحاضرة.
07 / READ & SEARCH

قراءة المحتوى والبحث

cat · lessRead files

عرض محتوى ملف، أو قراءته صفحة صفحة.

cat ~/linux-demo/hello.txt
less /etc/os-release
less للخروج اضغط q، والتنقل بالأسهم أو Page Up/Down. cat -n file يضيف أرقام الأسطر.
head · tailFirst / last lines

عرض أول أو آخر أسطر الملف.

head -n 5 /etc/passwd
tail -n 5 /etc/passwd
tail -f /var/log/auth.log
-n 5 عدد الأسطر. -f متابعة الإضافات الجديدة؛ قد لا يتوفر ملف السجل أو الصلاحية.
grepSearch text

البحث عن نص داخل الملفات أو ناتج أمر.

grep "PRETTY_NAME" /etc/os-release
grep -n "root" /etc/passwd
grep -i "linux" ~/linux-demo/hello.txt
-n رقم السطر · -i تجاهل حالة الأحرف · -r بحث متكرر داخل مجلد.
findFind files

البحث عن ملفات حسب الاسم أو النوع أو خصائص أخرى.

find ~/linux-demo -type f
find ~/linux-demo -name "*.txt"
find /tmp -maxdepth 2 -type d
-type f ملفات · -type d مجلدات · -name الاسم · -maxdepth عمق البحث.
للتجربة: اكتب نصًا في الملف باستخدام printf 'Linux is powerful\nKali is a distro\n' > ~/linux-demo/hello.txt ثم نفّذ cat وgrep. علامة > تستبدل محتوى الملف، لذلك استخدمها فقط على ملف التجربة.
متابعة tail -f اختيارية؛ اضغط Ctrl+C لإيقافها. يمكن استخدام ملف التدريب بدل سجل النظام غير المتاح.
08 / PERMISSIONS

الصلاحيات والمستخدمون

مين أنا؟

IDENTITY
$ whoami
$ id
$ groups

يعرض اسم المستخدم، معرّفات المستخدم والمجموعات، والمجموعات اللي المستخدم عضو فيها.

فهم chmod

PERMISSIONS
$ touch ~/linux-demo/script.sh
$ chmod u+x ~/linux-demo/script.sh
$ ls -l ~/linux-demo/script.sh

u المالك · g المجموعة · o الآخرون · + إضافة · - إزالة · x تنفيذ · r قراءة · w كتابة.

قراءة صلاحيات مثل -rwxr-xr--

OWNER

rwx = 7
قراءة + كتابة + تنفيذ

GROUP

r-x = 5
قراءة + تنفيذ

OTHERS

r-- = 4
قراءة فقط

مثال رقمي: chmod 754 script.sh يجعل صلاحيات المالك rwx والمجموعة r-x والآخرين r--. لا تغيّر صلاحيات ملفات النظام أثناء العرض.

sudo: يشغّل أمرًا بصلاحيات مرتفعة حسب إعدادات النظام. ما تستخدموش لمجرد التجربة؛ راجع الأمر قبل تنفيذه، خصوصًا أوامر الحذف أو تغيير الصلاحيات.
09 / SYSTEM & PROCESS

معلومات النظام والعمليات

uname · catSystem info

معلومات النواة ونظام التشغيل.

uname -a
cat /etc/os-release
hostname
-a يعرض معلومات متعددة عن النواة والجهاز. /etc/os-release يعرّف التوزيعة.
df · duDisk usage

مساحة الأقراص وحجم المجلدات.

df -h
du -sh ~/linux-demo
du -h --max-depth=1 ~/
df -h مساحة أنظمة الملفات بوحدات مقروءة · du -sh ملخص حجم المجلد.
freeMemory

عرض استخدام الذاكرة.

free -h
free -m
-h وحدات مناسبة · -m بالميبيبايت (MiB).
ps · topProcesses

عرض العمليات الجارية ومراقبتها.

ps
ps aux
top
ps aux عرض واسع للعمليات · top مراقبة تفاعلية؛ للخروج اضغط q.
كل الأوامر السابقة للقراءة والمراقبة فقط، ومناسبة لعرض مباشر دون تغيير إعدادات النظام.
10 / NETWORK BASICS

أوامر شبكة مفيدة

ipNetwork interfaces

عرض واجهات الشبكة والعناوين.

ip addr
ip route
ip link
addr عناوين IP · route جدول التوجيه · link حالة الواجهات. أوامر عرض بدون تعديل.
pingConnectivity check

اختبار الوصول إلى مضيف باستخدام ICMP.

ping -c 4 127.0.0.1
ping -c 4 1.1.1.1
-c 4 يرسل أربع محاولات ثم يتوقف. العنوان العام قد لا يستجيب بسبب الشبكة أو الجدار الناري.
ssSockets

عرض اتصالات ومنافذ الشبكة.

ss -tuln
ss -tunap
-t TCP · -u UDP · -l مستمع · -n أرقام بدل الأسماء · -a الكل · -p معلومات العملية (قد تحتاج صلاحية لرؤية كل التفاصيل).
curlFetch URL

إجراء طلب HTTP وعرض الاستجابة.

curl -I https://example.com
curl -L -I https://example.com
-I رؤوس الاستجابة فقط · -L اتّباع التحويلات. يحتاج اتصال إنترنت ووجود curl.
في Kali وأمن الشبكات: فهم العناوين والمسارات والمنافذ أساس قبل استخدام أدوات الفحص. اختبر فقط الأنظمة التي تملكها أو عندك تصريح واضح لاختبارها.
11 / HELP & PACKAGES

المساعدة وتثبيت البرامج

📖

اسأل النظام نفسه

BUILT-IN HELP
$ man ls
$ ls --help
$ apropos network

man دليل تفصيلي · --help مساعدة مختصرة لكثير من الأوامر · apropos يبحث في أوصاف صفحات الدليل، وقد يحتاج قاعدة بيانات محدثة.

📦

مدير الحزم APT

DEBIAN / KALI
$ apt search tree
$ apt show tree
$ sudo apt update
$ sudo apt install tree

ابحث واعرض معلومات الحزمة، وحدّث فهرس الحزم، ثم ثبّت برنامجًا عند الحاجة.

تنبيه: apt update يحدّث قوائم الحزم، وليس كل البرامج. التثبيت يحتاج صلاحية مسؤول واتصالًا بالإنترنت؛ مش ضروري تنفذه في البرزنتيشن.
الـ Flags بتختلف من أمر للتاني. ما تفترضش إن -r معناها واحد في كل الأوامر؛ ارجع إلى man command أو command --help.
البحث والعرض في APT يعتمدان على فهرس محلي وقد لا يعرض معلومات دون تجهيزه. أوامر sudo هنا للشرح فقط، وليست جزءًا من الديمو.
12 / PIPES & REDIRECTION

قوة لينكس: ربط الأوامر ببعض

Pipe |

يمرّر ناتج أمر كمدخل للأمر اللي بعده.

PIPELINE
$ ps aux | grep firefox
$ ip addr | grep "inet "

المثال الأول يبحث في العمليات عن Firefox؛ قد يظهر سطر grep نفسه حتى لو Firefox غير شغال. لتفادي مطابقة عملية البحث استخدم ps aux | grep "[f]irefox".

Redirect > و >>

توجيه الناتج إلى ملف بدل الشاشة.

OUTPUT REDIRECTION
$ echo "Hello Linux" > ~/linux-demo/hello.txt
$ echo "Second line" >> ~/linux-demo/hello.txt
$ cat ~/linux-demo/hello.txt

> يستبدل المحتوى، بينما >> يضيف في نهاية الملف.

;

ينفّذ الأمر التالي بعد السابق، حتى لو فشل الأول.

&&

ينفّذ التالي فقط لو السابق نجح.

2>

يوجّه رسائل الخطأ إلى ملف أو وجهة أخرى.

13 / SAFE LIVE DEMO

سيناريو عملي جاهز للعرض

نفّذ الأوامر دي بالترتيب. أوامر الملفات محصورة في مجلد تدريب جديد داخل مجلد المستخدم؛ بقية الأوامر للقراءة فقط. لا تحتاج صلاحيات root أو اتصال إنترنت. نفّذها في نفس جلسة الطرفية.

DEMO — copy one line at a time
# 1) اعرف مكانك وهوية المستخدم
pwd
whoami

# 2) جهّز مجلد تدريب وملفًا نصيًا
DEMO_DIR=$(mktemp -d "$HOME/linux-demo.XXXXXX")
[ -n "$DEMO_DIR" ] && printf 'Practice directory: %s\n' "$DEMO_DIR"
printf 'Linux is powerful\nKali is a distro\nTerminal practice\n' > "$DEMO_DIR/notes.txt"

# 3) اعرض المحتوى وابحث عن كلمة
ls -lah "$DEMO_DIR"
cat -n "$DEMO_DIR/notes.txt"
grep -in "linux" "$DEMO_DIR/notes.txt"

# 4) انسخ الملف واعرض معلومات النظام
cp -i "$DEMO_DIR/notes.txt" "$DEMO_DIR/notes-copy.txt"
uname -a
cat /etc/os-release

# 5) جرّب معلومات الشبكة
ip addr
ss -tuln

# 6) راجع النتيجة
find "$DEMO_DIR" -maxdepth 1 -type f
التجهيز: mktemp -d ينشئ مجلدًا جديدًا باسم فريد، وDEMO_DIR متغيّر يحفظ مساره. إذا فشل التجهيز، توقّف قبل أوامر الكتابة. احتفظ بنفس الطرفية أثناء الديمو.
لو نفّذت الديمو قبل العرض: لو ظهر سؤال من cp -i بسبب وجود نسخة سابقة، اكتب y للاستبدال أو n للاحتفاظ بها. تقدر كمان تتخطى أمر النسخ.
ما تنفذش في العرض: أوامر حذف واسعة مثل rm -rf، أوامر تغيير الشبكة/الجدار الناري، أوامر من الإنترنت لا تفهمها، أو أوامر بصلاحيات root دون حاجة.
